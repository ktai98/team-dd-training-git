# 社内ランチ情報

このフロアで食べられる店をまとめた、社内向けのメモです。

## 中身

| 場所 | 内容 |
| --- | --- |
| `shops/` | 店ごとのページ。`shops/README.md` が索引 |
| `members/` | メンバーの自己紹介 |
| `shared/` | みんなで編集するファイル |

## 編集のルール

- **店のページを追加したら、`shops/README.md` の索引にも必ず追加してください。** 索引から辿れないページは、無いのと同じです
- 営業時間は実際に行って確認した情報だけを書いてください

## 営業時間の見方

営業時間は「実際に行って確認した時刻」です。ラストオーダーはさらに早いことが
あるので、閉店 30 分前には入るようにしてください。

## 支払い方法

現金のみの店が多いです。各ページの「メモ」を見てください。
